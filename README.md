# Chest Peek — versión desde cero para Minecraft 26.2 (Fabric)

Implementación propia (sin código del original). Mira un cofre, barril o shulker y aparece un
resumen agrupado por tipo de ítem (cantidad total), ordenado de mayor a menor.

- Servidor autoritativo: valida chunk cargado, distancia y línea de visión real (anti-xray).
- Cofres dobles sumados. Tecla **O** para activar/desactivar (en memoria, sin archivo de config).
- Compilar: igual que `chest-preview-26.2` (JDK 25; ver su README, opción A o B).
- No pude compilar aquí; si algún nombre de 26.2 falla, ver la lista de candidatos en el otro README.
